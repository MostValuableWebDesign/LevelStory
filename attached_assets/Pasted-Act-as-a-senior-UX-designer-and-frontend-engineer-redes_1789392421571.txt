OVERALL DESIGN GOAL

Create a polished, chart-centered review workspace supporting this flow:

Generate a review set → select a trade → inspect chart and result → record human judgment → advance to the next trade.

Preserve every existing capability. Later stages will refine trade navigation, supporting panels, and responsive behavior.

VISUAL FOUNDATION

Use the existing styling system and component libraries.

Create a restrained light theme:
- Soft slate page background.
- White panels.
- Deep navy text.
- Royal blue primary actions and selection.
- Green/teal for positive results and successful states.
- Red for negative results and errors.
- Amber for warnings and shadow mode.

Preserve established chart colors and meanings. Color must supplement text, not replace it.

Use consistent spacing, subtle borders, approximately 10–12px panel corners, restrained shadows, readable text, and tabular numerals for financial values.

Reduce the graph-paper background, oversized introductory content, tiny uppercase labels, repetitive borders, and unused gray grid areas.

LAYOUT

1. Keep Generate, Chart Analysis, and Account Impact as the existing top-level modes. Present them in a compact navigation bar.

2. Use a compact Visual Review heading. Retain one clearly visible “Shadow mode — no live orders” indicator.

3. Before generation:
   - Show a focused setup area containing all existing fields, strategy toggles, descriptions, validation, and actions.
   - Replace the enormous blank results panel with a concise explanation of the review workflow.

4. During generation:
   - Keep the progress panel prominent.
   - Preserve synchronized loading indicators, percentage, completed sessions, elapsed time, ETA messaging, retries, and resume behavior.
   - Do not change the estimation algorithm or introduce fake progress.

5. After generation:
   - Collapse setup into an expandable Review set summary.
   - Show the actual generated date range, symbol, and session count.
   - Keep Edit settings, Generate, and Regenerate accessible.
   - Clearly distinguish the generated set’s settings from unsaved configuration edits.
   - Do not discard results simply because settings are expanded.

6. Create a desktop workspace with:
   - A left trade-navigation region, approximately 280–340px wide where space permits.
   - A substantially wider selected-trade/chart region.
   - Supporting details below the chart.

Move the chart ahead of long provenance and detection-funnel panels. Keep existing controls and supporting panels accessible while relocating them. Stage 2 will refine the trade rows and navigation; Stage 3 will reorganize the details.

At 1440×900, the selected-trade header and a meaningful portion of the chart should be visible without scrolling past the full trade list or technical metadata.
