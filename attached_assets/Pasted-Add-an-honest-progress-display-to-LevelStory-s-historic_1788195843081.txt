Add an honest progress display to LevelStory’s historical trade-candidate generation workflow.

Place it in the empty right-hand panel that currently says:

“Generate a set to open the review room.”

Do not display a fake percentage based only on a timer. Progress must come from actual backend work completed.

## Progress-circle design

While candidate generation is running, replace the empty message with a centered progress display containing:

- A large circular progress indicator.
- Percentage value in the center, such as `47%`.
- Royal-blue progress fill around the outer circle.
- A smaller royal-blue highlight arc that continuously rotates around the circle while work remains active.
- Current processing stage beneath the percentage.
- Completed sessions versus total sessions.
- Elapsed time.
- Optional estimated time remaining only when enough runtime evidence exists.

Elapsed: 18 seconds
