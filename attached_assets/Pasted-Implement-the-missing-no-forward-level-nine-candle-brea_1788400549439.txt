Current behavior

The application already freezes the target-level snapshot at entry.

When the frozen target plan has:

disposition === "NO_ELIGIBLE_KEY_LEVEL"

the application correctly uses +1R as the fallback target.

Preserve that behavior and add the following time-based management rule.

Authoritative rule

This rule applies only when no eligible forward key-level target was available in the frozen entry-time snapshot.

1. Calculate +1R using the actual modeled entry fill and authoritative initial protective stop:

   initialRisk = abs(entryFill - initialStop)

   Long:
   oneRPrice = entryFill + initialRisk

   Short:
   oneRPrice = entryFill - initialRisk

2. Do not count the entry/confirmation candle E toward the timer.

3. Count completed five-minute candles beginning with the first completed candle after E.

4. During candles 1 through 9:

   - Keep the original protective stop active.
   - Keep the +1R target active.
   - If the stop is reached first, exit at the stop.
   - If +1R is reached first, apply the existing 1R exit policy.
   - Do not activate breakeven early.

5. After the ninth post-entry candle closes, if neither the stop nor +1R has executed:

   - Activate breakeven management at the modeled entry-fill price.
   - Activation becomes effective beginning with candle 10.
   - Never retrospectively fill breakeven using candle 9.

6. If price is already favorable or equal to entry when breakeven activates:

   - Arm entry price as the protective breakeven stop for candle 10 onward.

7. If price is adverse when breakeven activates:

   - Do not fabricate a breakeven fill.
   - Keep the original protective stop active.
   - Arm a recovery-to-entry exit at the entry price.
   - For a long trade, exit when a subsequent candle reaches entry from below.
   - For a short trade, exit when a subsequent candle reaches entry from above.
   - Label this honestly as a recovery-to-breakeven exit, not as an intrabar stop fill.

8. If a later candle contains both the original protective stop and the breakeven/recovery price and intrabar order is unknown:

   - Apply the existing conservative adverse-first ambiguity policy.
   - Record the ambiguity explicitly.
   - Do not assume breakeven happened first.

9. Preserve the existing multi-contract behavior:

   - If +1R is reached before the timer, use the existing partial-at-1R and runner policy.
   - If the nine-candle rule activates before +1R, apply breakeven protection to all remaining contracts.
   - Never create duplicate exits or more exited quantity than the original position.
