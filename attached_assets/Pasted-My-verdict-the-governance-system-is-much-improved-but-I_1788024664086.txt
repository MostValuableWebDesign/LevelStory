### Important findings

1. False-positive teaching is lost

The interface only attaches structured teaching data for `missed_trade` and `rule_needs_clarification`. Selecting `false_positive_trade` saves a review but not a permanent teaching example.

See [visual-review.tsx](</Users/jawanhiggins/Downloads/LevelStory-main 11/artifacts/levelstory/src/pages/visual-review.tsx:409>).

2. Validation can silently use simulated candles

If persisted evidence lacks candle arrays, the validator calls `createMarketSnapshot` without historical candles. That function falls back to simulated data. Validation must instead fail closed with “immutable candle evidence missing.”

See [proposal-validator.ts](</Users/jawanhiggins/Downloads/LevelStory-main 11/artifacts/api-server/src/lib/proposal-validator.ts:81>).

3. Performance metrics are not candidate backtest results

Win rate, P&L, drawdown, and profit factor reuse the teaching example’s existing `outcomeSnapshot`. The candidate does not receive a new simulated fill and outcome replay. Therefore, these metrics do not prove what the changed rule would have produced.

See [proposal-validator.ts](</Users/jawanhiggins/Downloads/LevelStory-main 11/artifacts/api-server/src/lib/proposal-validator.ts:108>).

4. The immediate-next-candle rule is not truly validated

The check only confirms that both timestamps exist. It does not prove the entry candle immediately follows the patience candle by exactly five minutes.

See [proposal-validator.ts](</Users/jawanhiggins/Downloads/LevelStory-main 11/artifacts/api-server/src/lib/proposal-validator.ts:181>).

5. Activated settings can be overridden during backtesting

The active strategy configuration is loaded, but OHLC-mode backtests then overwrite `patienceEntryBufferTicks` with the request-level value. This means activation may affect Visual Review but not the primary historical backtest path.

See [phase9.ts](</Users/jawanhiggins/Downloads/LevelStory-main 11/artifacts/api-server/src/lib/phase9.ts:1399>).

6. Retiring an active candidate is not atomic

The proposal transition and strategy-version update happen separately, and the active-strategy cache is not refreshed afterward. A failure could leave inconsistent records—or the retired configuration temporarily continuing in memory.

See [governance-store.ts](</Users/jawanhiggins/Downloads/LevelStory-main 11/artifacts/api-server/src/lib/governance-store.ts:559>).

- Rule changes are typed and currently restricted to the 3-or-4-tick patience-entry buffer.
