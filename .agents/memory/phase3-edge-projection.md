---
name: Phase 3 edge projections
description: How historical edge-validation metrics treat canonical edge ownership and secondary strategy matches.
---

Independent edge totals must use the candidate's canonical primary edge. Secondary matched edges belong in confluence and drill-down provenance, but must not multiply one physical P→E sequence into every edge's population.

**Why:** The active strategy can report several qualified evaluations for one causal sequence; counting every match as an independent candidate makes edge metrics look populated by the same trade and obscures physical deduplication.

**How to apply:** When projecting candidate evidence into edge summaries, filter by primary ownership and preserve matched-edge lists for confluence, grading, and audit evidence.
