---
name: Funnel stage naming
description: Naming and interpretation rules for shared qualification funnel stages.
---

Shared funnel stages must describe the common qualification boundary, not a single strategy's rule family. Keep the rule-key mapping strategy-specific inside the stage.

**Why:** A shared stage named for continuation made reversal-specific counter-trend failures appear to be universal continuation requirements.

**How to apply:** Use strategy-neutral stage identifiers and UI labels; explain the strategy-specific rule family in the candidate detail and preserve separate rejection attribution.
